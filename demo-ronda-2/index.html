Ecuaciones de segundo grado, paso a paso

1.Reconocerla

Es de segundo grado si, una vez ordenada, la x más alta está al cuadrado. Se escribe así:

ax² + bx + c = 0 con a ≠ 0
  • a es el número que acompaña a x².
  • b es el que acompaña a x.
  • c es el número suelto.

Cada uno se lleva su signo. En x² − 5x + 6 = 0 tienes a = 1, b = −5 y c = 6. Si no ves número delante de x², es un 1.

Antes de nada: iguala a cero

Si te dan x² = 5x − 6, pasa todo a un lado: x² − 5x + 6 = 0. Ahora sí puedes leer a, b y c. Leerlos sin ordenar es la forma más rápida de empezar mal.

2.Las incompletas

Si falta b o falta c, no necesitas la fórmula. Se resuelven más rápido y con menos riesgo de error.

Sin b: ax² + c = 0

Despeja x² y haz la raíz. No olvides que salen dos: la positiva y la negativa.

  1. 2x² − 18 = 0
  2. 2x² = 18
  3. x² = 9
  4. x = ±√9 = ±3 → x = 3 y x = −3

Si al despejar te queda x² igual a un número negativo, no hay solución real: ningún número al cuadrado da negativo.

Sin c: ax² + bx = 0

Saca x factor común. Un producto vale cero si alguno de los factores vale cero.

  1. x² − 4x = 0
  2. x · (x − 4) = 0
  3. x = 0 o bien x − 4 = 0
  4. x = 0 y x = 4

No dividas entre x para «simplificar»: perderías la solución x = 0.

3.La fórmula general

Sirve para cualquier ecuación de segundo grado, completa o no:

x = −b ± √b² − 4ac2a

Aplícala siempre en este orden y no te saltes pasos:

  1. Iguala a cero y apunta a, b y c con su signo.
  2. Calcula primero el discriminante, b² − 4ac, aparte.
  3. Haz su raíz.
  4. Escribe las dos soluciones por separado: una con + y otra con −.

Separar el discriminante parece un paso de más. Es justo donde se cometen casi todos los errores de signo.

4.El discriminante

Es lo de dentro de la raíz: Δ = b² − 4ac. Te dice cuántas soluciones hay antes de terminar la cuenta.

Δ > 0

Dos soluciones distintas.

Δ = 0

Una solución (las dos coinciden).

Δ < 0

Ninguna real: no existe la raíz de un negativo.

Si te sale negativo, para ahí. La respuesta es «no tiene solución real» y no hace falta seguir.

5.Ejemplos resueltos

Dos soluciones

x² − 5x + 6 = 0

  1. a = 1, b = −5, c = 6
  2. Δ = (−5)² − 4 · 1 · 6 = 25 − 24 = 1 → positivo, habrá dos.
  3. √1 = 1
  4. x = 5 ± 12 → 62 = 3 y 42 = 2

x = 3 y x = 2

Fíjate en el paso 4: como b = −5, el −b de la fórmula es +5.

Dos soluciones, con a ≠ 1

2x² + 3x − 2 = 0

  1. a = 2, b = 3, c = −2
  2. Δ = 3² − 4 · 2 · (−2) = 9 + 16 = 25
  3. √25 = 5
  4. x = −3 ± 54 → 24 = 12 y −84 = −2

x = 1/2 y x = −2

Como c es negativo, −4ac se convierte en una suma. Menos por menos.

Una solución

x² − 6x + 9 = 0

  1. a = 1, b = −6, c = 9
  2. Δ = 36 − 36 = 0 → una sola solución.
  3. x = 6 ± 02 = 3

x = 3

Sin solución real

x² + 2x + 5 = 0

  1. a = 1, b = 2, c = 5
  2. Δ = 4 − 20 = −16 → negativo. Paras aquí.

No tiene solución real

6.Los errores de siempre

El signo de −b cuando b ya es negativo

Si b = −5, entonces −b = +5. Y b² = (−5)² = 25, nunca −25: un cuadrado no es negativo.

Malx = (−5 ± 1) / 2
Bienx = (5 ± 1) / 2

Truco: escribe b entre paréntesis al sustituir, −(−5) y (−5)², y luego opera.

Dividir entre 2a solo una parte

La raya de fracción va debajo de todo: de −b y de la raíz.

Malx = −3 ± 5/4
Bienx = (−3 ± 5) / 4

Olvidar el ± y quedarse con una solución

Si el discriminante es positivo, hay dos soluciones. Si das una, el ejercicio está a medias.

Malx = (5 + 1) / 2 = 3
Bienx = 3 y x = 2

7.Ejercicios

Hazlos en papel y abre la solución solo para comprobar.

x² − 16 = 0

Incompleta sin b. x² = 16 → x = 4 y x = −4

3x² + 12x = 0

Incompleta sin c. 3x · (x + 4) = 0 → x = 0 y x = −4

5x² + 20 = 0

x² = −4. Ningún número al cuadrado da negativo → No tiene solución real

x² − 7x + 10 = 0

Δ = 49 − 40 = 9, √9 = 3. x = (7 ± 3) / 2 → x = 5 y x = 2

x² + 4x + 4 = 0

Δ = 16 − 16 = 0. x = −4 / 2 → x = −2

2x² − x − 3 = 0

a = 2, b = −1, c = −3. Δ = 1 + 24 = 25. x = (1 ± 5) / 4 → x = 3/2 y x = −1

x² + x + 1 = 0

Δ = 1 − 4 = −3 → No tiene solución real

x² = 3x + 4ojo, primero ordena

x² − 3x − 4 = 0. Δ = 9 + 16 = 25. x = (3 ± 5) / 2 → x = 4 y x = −1

Preguntas frecuentes

¿Tengo que usar la fórmula siempre?

No. Funciona siempre, pero en las incompletas es más lento y más fácil equivocarse. Si falta b o falta c, despeja o saca factor común. La fórmula es para cuando están los tres.

¿Cómo sé si lo he hecho bien?

Sustituye cada solución en la ecuación original. Con x = 3 en x² − 5x + 6: 9 − 15 + 6 = 0. Si da cero, está bien. Comprobar cuesta treinta segundos; entregar una solución mal cuesta el ejercicio entero.

¿Qué hago si el discriminante no tiene raíz exacta?

Déjala indicada. En x² − 3x + 1 = 0 sale Δ = 5, así que x = (3 ± √5) / 2. Es una respuesta correcta y completa; no hace falta pasarla a decimales salvo que te lo pidan.

¿Y si a es negativo?

Puedes aplicar la fórmula igual, o multiplicar toda la ecuación por −1 para que a quede positivo. Las soluciones son las mismas. Menos signos negativos, menos ocasiones de fallar.

¿Qué significa «no tiene solución real»?

Que no hay ningún número real que la cumpla. No es que te hayas equivocado: es la respuesta. Si el discriminante es negativo, escríbelo así y pasa al siguiente ejercicio.
