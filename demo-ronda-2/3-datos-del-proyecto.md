# Datos del proyecto

## Qué es
Una guía gratuita para aprender a resolver ecuaciones de segundo grado (ax² + bx + c = 0)
paso a paso, sin registro.

Nombre y dominio:

## Para quién
Estudiantes de secundaria y de bachillerato que tienen examen, y adultos que vuelven a
estudiar y no se acuerdan. El problema típico: se saben la fórmula de memoria pero se
equivocan con los signos o no saben qué hacer cuando falta un término.

## Qué incluye
1. Cómo reconocer una ecuación de segundo grado y quién es a, b y c.
2. Las incompletas (sin b o sin c): se resuelven sin fórmula.
3. La fórmula general: x = (−b ± √(b² − 4ac)) / 2a.
4. El discriminante (b² − 4ac): si es positivo hay dos soluciones, si es cero una y si es
   negativo ninguna real. Se sabe antes de terminar la cuenta.
5. Ejemplos resueltos paso a paso, uno de cada caso.
6. Los errores de siempre: el signo de −b cuando b ya es negativo, dividir entre 2a solo una
   parte, olvidar el ± y quedarse con una solución.
7. Ejercicios con la solución para comprobar.

## Ejemplo que tiene que salir
x² − 5x + 6 = 0 → a = 1, b = −5, c = 6 → discriminante 25 − 24 = 1 → x = 3 y x = 2.
